# 加载图像 (路径) 🍕🅩🅕

从指定地址读取加载图像, 支持 网络地址、本机完整路径、本机相对路径

## 特点

- 支持 `本机图片路径` (**相对路径**、**完整路径**、**~**、**~user** 等))
- 支持 `网络图片地址` (**http**、**https** 协议)
- 支持 `RGBA` 格式导出图像
- 支持设定 `默认兜底图像`

## 参数

- **image_path**: 要加载图像的网络地址 或 本地路径 (支持相对路径)

    > 默认值 `./input/example.png`

- **default_image**: 当指定的加载地址无效或读取失败时, 使用的兜底图像

- **RGBA**: 是否使用 RGBA 格式导出图像
